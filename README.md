# 📚 Mid-Semester Exam Preparation Tracker

An interactive, high-aesthetic web application to track syllabus progress, tick off completed topics, take formula notes, and prepare for mid-semester examinations.

## 🚀 How to Open
1. **Directly in Browser**: Double-click [`index.html`](index.html) or [`tracker.html`](tracker.html) to open in Chrome, Safari, Edge, or Firefox.
2. **VS Code Live Server**: If using the Live Server extension, right-click `index.html` and choose **Open with Live Server**.
3. **Markdown Checklist**: Open [`mid_sem_prep_checklist.md`](mid_sem_prep_checklist.md) to view or tick checkboxes directly in your IDE.

## 🎯 Subjects Covered
1. **Digital Logic Design (DLD)**: Number systems, complements, binary codes (BCD, Excess-3, Gray, ASCII), universal logic gates, Boolean algebra, K-Maps, Quine-McCluskey tabulation, MUX/DEMUX, encoders/decoders, adders/subtractors.
2. **Data Structures & Algorithms (DSA)**: Complexities ($O, \Omega, \Theta, o, \omega$), multi-dimensional array ordering (Row-major & Column-major formulas), Searching (Linear, Binary), Sorting (Bubble, Selection, Insertion, Merge, Quick), Stacks (applications, conversions), Queues (Circular, Deque, Priority), Linked Lists (Singly, Doubly, Circular, Doubly Circular).
3. **Java (OOPs)**: JDK/JRE/JVM/JIT architecture, OOP principles, data types, type conversions, control flow, loops, classes & objects, methods, constructor overloading, `this`, `static` members, nested classes, arrays, Strings & String pool, Scanner, Wrapper classes.
4. **Discrete Mathematics**: Relations (reflexive, symmetric, antisymmetric, transitive), zero-one matrices & digraphs, equivalence relations & partitions, Posets & Hasse diagrams, Mathematical Induction (weak & strong), recursively defined functions, linear recurrence relations (homogeneous & non-homogeneous cases), divisibility, Euclidean algorithm & Bézout coefficients, linear congruences & CRT, Fermat's Little Theorem, applications & classical cryptography.
5. **Linear Algebra & Differential Equations**: Systems of linear equations, REF/RREF, Gauss & Gauss-Jordan elimination, homogeneous & non-homogeneous systems, applications (resources, chemical balancing, network analysis, electrical networks, Leontief economic model), Eigenvalues & Eigenvectors, matrix diagonalization, Markov chains, population growth models, systems of linear differential equations, vector spaces, spanning sets, linear independence, basis & dimension, linear transformations, kernel & range, rank-nullity theorem.

## ✨ Features
- **One-Click Checkpoints**: Click on any topic to mark as Done. Select "In Progress" or "Pending" from the dropdown.
- **Formula & Revision Notes (📝)**: Click the note icon on any topic to record tricky formulas, edge cases, or solved questions.
- **⭐ Star Priority**: Pin difficult topics to your Starred priority list for fast revision before the exam.
- **Live Readiness Gauge & Progress Bars**: Real-time overall and subject-specific completion percentages.
- **Exam Countdown**: Live countdown timer (Days, Hours, Minutes, Seconds) with customizable target date.
- **Instant Search & Filter Chips**: Real-time filtering across topic names, descriptions, and personal notes.
- **Local Persistence & JSON Backup**: Automatically saves to browser `localStorage`. Includes Export and Import JSON backup buttons.
- **Printable**: Formatted with print styles to print a clean physical revision checklist.
